# 管理后台界面

视觉方向：浅灰工作面、白色表格、深色侧栏，使用单一绿色强调操作与当前状态；信息密集但留出明确的列间距。

内容顺序：总览先展示请求、用量和费用；账户页面展示开关、并发和额度；请求详情用时间线关联排队、绑定代次、上游尝试和计量；模型、Key、配置与管理员审计各有独立入口。

交互方向：导航切换使用短淡入，详情抽屉平移进入，按钮和表格行以轻微颜色变化表达可操作性。减少动态效果偏好下关闭动画。定时刷新只更新列表与总览，不覆盖正在编辑的表单。

单次请求详情包含请求/Key/会话/线程 ID、模型及请求档位、账户与绑定代次、上游请求 ID/模型/HTTP 状态/调用次数、排队/响应头/首事件/首内容/总耗时、配置版本、Token 用量与完整性、实际档位和分项金额，以及事件时间线和身份映射。后台不保存请求正文、密文摘要或可能引用用户正文的上游错误原文；具体上游错误说明只返回给本次调用的客户端，后台保留分类后的错误。

请求列表按「时间、模型、非缓存输入 / 输出、费用、账户、首字 / 总耗时、状态」排列。请求 ID 与绑定代次放在详情中；模型下方显示请求思考等级，未知历史值显示 `—`；缓存输入在 Token 下方使用 `↓` 标记。费用仅显示金额，实际 Fast/priority 档位且已知倍率时附圆形 `×倍率` 标记。悬浮或键盘聚焦金额可查看对应历史价格版本的标准输入/输出/缓存单价、实际分项金额与倍率，不使用当前价格重新解释旧请求。账户列显示当前账户名称。

首字耗时为排队耗时加上派发至首段内容事件的耗时（首段内容可以是文本、推理或工具参数）。TPS 为输出 Token ÷ 总耗时（秒），输出 Token 包含上游计入的推理 Token；用量不完整、缺少时间或总耗时非正时显示 `— t/s`。查看计费悬浮框时暂停列表定时刷新，避免内容跳动。

「本次请求改写」逐字段显示位置、传入 ID、转发 ID 和处理方式（归一化、自动补充、未转发、还原旧别名、保持不变）。按本次实际准备的请求记录，已有映射复用也留有对照；请求头、平铺和嵌套元数据按各自位置显示。默认显示变更，可搜索字段或 ID，并勾选显示未改写项。没有逐请求记录的历史请求明确显示缺失提示；下方「历史绑定与累计映射」用于单独查阅累计信息。

对照仅保存允许列表中的身份字段和正文顶层 item/call ID，不保存授权头、工具内容、任意元数据或密文。单次最多 2,000 项，每个 ID 最多 512 字节；被省略的正文标识项显示数量。限额只影响审计采集，不改变转发内容。记录随请求审计保留策略清理。

界面不显示凭证版本或价格版本标记。授权到期时间在账户详情展示；金额悬浮详情与模型价格表展示具体单价、金额和倍率。后端仍按历史价格版本计费和读取数据。

账户页使用滑块启停，移除引导文案；5h/7days 主额度上下排列，Spark 等独立额度只在详情中展示，不代替缺失的主额度。账户金额按请求结束时间统计最近 5 小时与 7 天的已计价金额，未完整计价次数通过星号悬浮显示。周总金额估算为当前周重置周期内的已计价样本金额 ÷ 上游额度消耗百分比增量 × 100%；至少需要 1% 增量，忽略不同重置周期数据，百分比回落后重新选择样本起点。Spark 调用不计入主额度金额样本；历史采集样本会标注，估算随价格、模型组合及网关外使用而变化。

账户模型范围显示实际已选的上游模型；编辑窗口支持逐项勾选、全选、清空和同步上游。保存后采用明确的模型范围，空选择表示该账户不接受任何模型，后续同步不会重新加入已移除项。只修改当前账户，不删除全局模型或历史记录。

账户页采用单账户圆角面板：名称、启停与设置位于顶部，并发、额度、金额与估算居中，模型范围在底部展开。统计数字使用细线图标与浅色圆角容器，模型和数量使用圆角标签；窄屏将四列信息排成两列。账户页金额摘要显示两位小数，悬停或键盘聚焦可读取完整金额与样本说明，账户详情仍显示完整精度。按钮、模型选择项与滑块使用轻微过渡，并遵循减少动态效果的系统偏好。

分组页支持创建、重命名和删除空分组，显示账户数、已启用账户数与 Key 数。账户设置、导入及新授权支持选择多个分组；Key 创建和编辑选择一个分组。账户和 Key 页均支持分组筛选，名称以圆角图标标签显示。默认分组不可删除，有账户或 Key 的分组需先移出成员才能删除。请求详情与审计记录请求当时的分组 ID。

## OAuth 额度重置

账户卡片显示最近查询的可用重置次数，提供「查询与重置」入口。详情抽屉显示全部凭据及状态、获得时间、到期时间，标记最早到期的有效凭据。已过期、已使用、使用中条目保留显示，无到期时间明确标注。重置动作一次使用一个凭据；执行过程中禁用按钮，结果未确认时显示「核实并重试」。查询失败保留旧快照与查询时间。重置后刷新账户额度与次数，独立展示刷新失败，避免把重置成功误报成失败。

## Search 计费

模型与价格页提供全局 Search 单价设置（人民币/次），留空与免费 0 明确区分。请求列表增加接口筛选与 Search 标记，Search 用量展示成功次数，悬浮计费详情展示当次单价和金额。用量费用页独立展示 Search 次数和费用，账户详情同步显示账户累计 Search 次数及费用；总人民币费用包含 Search。

请求追踪列表有独立的「接口类型」列，Responses 使用蓝色标记，Search 搜索使用紫色标记。新请求同时保存入站 stream 开关，Responses 显示「流式」或「非流式」；历史记录没有保存开关时仅显示 Responses，不推测模式。请求详情展示同样的类型标记。

请求详情的「请求接入诊断」展示失败阶段、请求体解析状态、会话与线程的解析来源，并逐行显示收到的身份字段、受限值和有效/空/无效状态。完整受限诊断可展开；没有采集信息的旧记录不推测回填。

运行配置的「并发与容量」包含「单 session 并发上限」，默认 2，允许 1–1000。配置保存后立即生效：上调放行符合其他容量条件的排队线程，下调等待在途请求自然收尾；同一 thread 始终串行。队列 API 还提供 thread ID、当前 session 并发和上限，便于区分账户空闲但会话仍需等待的情况。

请求详情在触发加密推理恢复时展示独立区块：HTTP 400 / invalid_encrypted_content、移除密文字段和空条目的计数、实际调用次数，以及每次收到的 HTTP 状态、响应头耗时和上游请求 ID。结果区分恢复成功、处理中、补发未完成和未补发；若清理后因取消或账户状态变化停止，不能显示为已恢复。提示被移除的加密推理状态会丢失。相关时间线只保存操作事实，不保存密文或摘要。

请求详情增加「Turn State 观察」：客户端传入值及每次上游响应值分开展示，标注尝试序号与 HTTP 状态；默认折叠具体值，可展开查看、选择复制。区分未携带、空字符串、多值、截断、省略及历史未采集；未收到响应头不误报为上游未返回字段。入站值继续丢弃，普通 Responses 和 Compact 的响应头处理均沿用原逻辑。只在详情接口返回原值，不进入请求列表或错误汇总；时间线只显示有无字段，并指向详情区块。
