## 模块

五个 crate 已建立并遵守核心端口依赖方向：`xxgate-core` 定义业务规则和用例；`xxgate-codex` 实现入站与提供方适配；`xxgate-transport` 封装单次 HTTP；`xxgate-postgres` 实现存储和迁移；`xxgate-server` 装配服务、后台任务、管理 API 与嵌入式 Web 静态资源。

后台使用原生 JavaScript/CSS，无需 Node 构建步骤；脚本仅用于启动和测试。响应、usage 和 ID 转换基于 `serde_json`，不会替换提示词或工具参数中的任意字符串。

## 已确定的首版选择

| 项目 | 实现选择 |
|---|---|
| 同会话多线程 | 单 session 默认 2 并发，可热更新为 1–1000；同 thread 串行，不同 thread 并行并共享绑定代次 |
| 非流式调用 | 上游 SSE，最终响应对象转 JSON；队列失败保留 HTTP 错误状态 |
| 模型发现 | 各账户 OAuth 获取 Codex 模型列表，保存快照并汇总去重；失败保留旧快照 |
| 上下文压缩 | 独立 Compact JSON 与 Responses Remote V2；详情记录压缩方式与结果 |
| 后台生成 / 引用 | 明确不支持，要求显式可迁移历史 |
| 价格 | 人民币十进制，分项 8 位小数；Fast 为标准单价 × 模型倍率，历史版本固定 |
| 队列与容量 | 2000 条、全局 200 并发、默认账户 2 并发、默认 session 2 并发、512 MiB 预算 |
| 额度 | 请求响应头/SSE + 每 300 秒查询，900 秒后过期；保留上游重置时间 |
| 汇总保留 | 小时汇总长期保留，明细/审计按运行配置清理 |
| 日志与指标 | tracing JSON、请求/管理员数据库审计、认证后的 Prometheus 指标；暂无 OTLP exporter |
| 管理员认证 | 单一管理员，12 小时会话，全局每分钟最多 10 次登录尝试 |

## 传输与兼容性

出站客户端固定 reqwest `0.12.28`、hyper `1.8.1`、hyper-util `0.1.20`、native-tls `0.2.14`、rustls `0.23.36`，Codex 基线为 `rust-v0.153.4`（`3d2ee51ca2d5db578f328aa75e20aa22c0197c9a`）。TLS 可按账户选择 native 或 rustls。连接池按账户隔离，凭证刷新不改变安装 ID。

依赖版本相同不代表所有网络行为一致：操作系统/TLS 实现、代理、根证书、编译 feature 和网关禁止重试的策略均影响实际请求。当前不发送宿主 attestation，不实现压缩请求入站。User-Agent 按运行主机生成，可在账户设置修改。

`eventsource-stream 0.2.3` 的 leading BOM 处理在分片测试中触发 UTF-8 边界 panic。网关在交给该解析库前去除流开头 BOM，并按 SSE 空行组装带大小上限的完整事件；注释不构成模型事件、不延长上游事件空闲期限。

图片计量仅使用上游返回的数值字段，不凭图片尺寸推算 Token。按张价格和图片工具 Token 价格互斥。Responses 图片工具表达参考 [官方文档](https://developers.openai.com/api/docs/guides/tools-image-generation)；OAuth 路径的实际能力仍需实测。
